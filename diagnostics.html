Test between two tabs
  1. Keep this receiver open. In the shader page, click Prepare Shader.
  2. Drag the prepared file over this tab, wait for tab activation, then drop into the box above. Alternatively place two windows side by side.
  3. Look for one file with the right name, size and SHA-256. An empty file list means the browser did not expose the file to this receiver. A missing drop event can also mean the drag never reached the box.
  4. Repeat against a receiver hosted on another trusted origin to investigate cross-origin restrictions, then test the real game separately. Same-origin success alone is not enough.
Record the browser version, operating system, source and target origins, full file metadata and the game’s actual response. For a cross-origin test, serve this project’s unchanged receiver on a second static host. Do not disable browser security or inject code into Bloxd.io.
The receiver only reads small dropped ZIPs (up to the configured memory limit) to hash them. Clear results to remove metadata; file references are not retained after processing.
